## Project scripts (relative to the repository root)

### Entry points

| Path | Used for |
|---|---|
| `streamlit_app/app.py` | Streamlit UI (tabs, editors, timeline, map, charts) |
| `streamlit_app/i18n.py` | Croatian/English string tables |
| `ccus_core/engine.py` | `ScenarioEngine` facade (JSON in → `SimulationResult` out) |
| `docs/whitepaper/build_whitepaper.py` | regenerates the whitepaper and its figures |

### Core modules

| Path | Used for |
|---|---|
| `ccus_core/models/scenario.py` | root scenario document and validation |
| `ccus_core/models/emitter.py` | emission curves (constant, piecewise, power law, polynomial), onboarding |
| `ccus_core/models/edge.py` | temporal edge states, upgrades, tariffs |
| `ccus_core/models/connection.py` | many-to-many emitter→sink access |
| `ccus_core/models/node.py` | nodes, ports, locations |
| `ccus_core/models/sink.py` | storage sinks, reservoir properties and defaults |
| `ccus_core/models/policy.py` | ETS, price paths, unit costs, Fisher relation |
| `ccus_core/network/graph.py` | time-dependent graph |
| `ccus_core/network/routing.py` | capacity-constrained routing |
| `ccus_core/network/pressure.py` | hub pressure cascade (Darcy–Weisbach / Haaland) |
| `ccus_core/simulation/solver.py` | chronological solver |
| `ccus_core/simulation/reservoir.py` | variable-rate material balance |
| `ccus_core/simulation/geothermal.py` | geothermal doublet coupling |
| `ccus_core/simulation/pressures.py` | annual pressure table per path |
| `ccus_core/simulation/adapters.py` | duck-typed inputs for the legacy engineering classes |
| `ccus_core/finance/cashflow.py` | cash-flow configuration |
| `ccus_core/finance/stakeholders.py` | per-party statements, entity views, cost charts |
| `ccus_core/io/commented_json.py` | compact JSON input/output |
| `ccus_core/io/scenario_repository.py` | named scenarios (`scenario_001`, …) |
| `ccus_core/io/excel_import.py` | workbook → scenario |
